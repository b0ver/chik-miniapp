# Чик! — Telegram Mini App для фокус-группы

Тестовое приложение для мастеров и клиентов. Бот: [@checkmytime_bot](https://t.me/checkmytime_bot). Публичное демо: [b0ver.github.io/chik-miniapp](https://b0ver.github.io/chik-miniapp/).

## Что внутри

- Стартовый экран для участников из сторис, два сценария и приглашение в фокус-группу.
- Настройка мастера, услуг и часов. Запись клиента, перенос и отмена.
- Telegram WebApp SDK: разворот приложения, оформление контейнера, безопасные отступы, кнопка назад и отклик при подтверждении.
- Кнопка фокус-группы ведёт в отдельный тёмный [инстанс реальной записи](https://b0ver.github.io/chik-focus/): выбор времени, контакт и подтверждение. Само демо продолжает использовать только локальные вымышленные данные.
- Аватар Чик — календарик с улыбкой-галочкой, бот-профиль и локальная настройка через API.

Это демо. Используйте вымышленные контакты. Введённые имя и телефон остаются в localStorage устройства, форма не отправляет их на сервер. Telegram initData и данные профиля не сохраняются и не используются для авторизации. Платежей, реальных сообщений и общих записей между устройствами нет. Дата демо обновляется каждый день по Москве, при смене дня тестовые данные восстанавливаются.

## Публикация на GitHub Pages

Источники интерфейса — `dist/`. Команда `node scripts/build.mjs` готовит `docs/`, который публикуется из ветки `main`. Отдельный сервер приложения и установка зависимостей не нужны. Файл `.nojekyll` сохраняет публикацию обычных статических файлов.

После правки исходников выполните сборку, проверку JavaScript и отправьте изменения в репозиторий. GitHub Pages опубликует новую версию. Адрес и имя бота задаются в `dist/config.js`.

## Настройка бота

Секрет хранится только в `.env.local` с правами 600. Файл исключён из Git. Не добавляйте токен в HTML, JavaScript, документацию и GitHub Actions.

- `python3 scripts/setup_bot.py --check` проверяет, что токен относится именно к `checkmytime_bot`.
- `python3 scripts/setup_bot.py --configure` задаёт имя, короткое и полное описания, аватар и кнопку меню «Открыть Чик!». Скрипт сначала проверяет публичную страницу и затем читает настройки обратно.
- Публичные тексты и адрес приложения находятся в `bot-profile.json`. Секрета там нет.

Чтобы прямая ссылка `https://t.me/checkmytime_bot?startapp=focus` открывала главное Mini App, включите Main Mini App у @BotFather: `/mybots` → `@checkmytime_bot` → **Bot Settings** → **Configure Mini App** → **Enable Mini App** и укажите `https://b0ver.github.io/chik-miniapp/`. Наличие кнопки меню и настройка главного Mini App — отдельные настройки Telegram.

GitHub Pages не выполняет серверный код. Открытие приложения работает через кнопку меню и включённое Main Mini App. Пользовательские сообщения боту не превращаются в заявку на фокус-группу; кнопка участия ведёт на отдельную страницу бронирования встречи с организатором. Для владельца подключён отдельный [кабинет организатора с личными уведомлениями](https://github.com/b0ver/chik-focus#личный-кабинет-организатора-в-telegram) в Google Apps Script: он показывает реальные встречи фокус-группы. Публичное демо мастера продолжает использовать тестовые локальные записи.

## Проверка

Публикация от 19 октября 2026: GitHub Pages успешно развёрнут; публичная страница и сценарий записи проверены в браузере. Telegram API подтвердил имя, оба описания, наличие фото и адрес кнопки меню. Владелец включил Main Mini App; Telegram API подтвердил has_main_web_app=true. Прямая ссылка для сторис: https://t.me/checkmytime_bot?startapp=focus. Открытие на реальном телефоне остаётся отдельной проверкой.

Перед публикацией проверяются стартовый экран, оба сценария, переход к организатору без автоматической отправки сообщения, отображение на телефоне и отсутствие токенов в публикуемых файлах. Настоящее открытие в Telegram нужно отдельно проверить с телефона после привязки бота.

## Изображение

Аватар сгенерирован встроенным ImageGen, затем сохранён в PNG и перекодирован в JPG для Telegram без изменения композиции. Файлы: `dist/assets/chik-avatar.png` и `dist/assets/chik-avatar.jpg`.

Промпт: квадратный аватар для «Чик!», один весёлый лаймовый календарик с выразительными глазами и улыбкой-галочкой, тактильная 3D-иллюстрация, тёмно-зелёный фон, кремовые детали, безопасная зона под круглый кроп, без текста и водяных знаков.
